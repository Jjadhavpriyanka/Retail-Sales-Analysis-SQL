# Retail Sales Analysis Using SQL

## Project Overview

This project analyses a global retail sales dataset using SQL. The dataset was downloaded from Kaggle. 


The objective is to identify:

- Sales trends
- Top performing products
- Customer behaviour
- Regional performance
- Profitability insights

## Tools Used
 
- SQL (MySQL)
- GitHub

## Dataset

Global Superstore Dataset

## Analysis Questions

1. What are the total sales and profit?
2. Which products generate the highest revenue?
3. Which regions perform best?
4. Who are the top customers?
5. What are the sales trends over time?
